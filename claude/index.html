How this Instagram runs itself, built with Claude

Two editors, a post every day, and we still approve every single one. The full setup, free.

Our Instagram, LinkedIn and YouTube Shorts run on a pipeline we built with Claude Code. Ideas go in on Telegram. Claude plans the week, drafts the scripts and captions, edits the reels in code, and a tiny server posts them on time. We step in at three checkpoints and nothing goes out without our yes.

This is the whole thing: what it does, the stack, the steps, the prompts, and the rules we learned the hard way.

From Cutcult, a post-production studio. Instagram: @cutcult.in

The pipeline, step by step

1. Write your brand down first

Before any code. This is the step that makes or breaks it, and the one AI can't do for you.

  • Brand guide: colours, fonts, logo rules, safe zones.
  • Voice: how you talk. Words you use, words you never use.
  • Banned list: the generic stuff ("unlock", "elevate", stock smiling people). Claude checks every piece against it.
  • Taste log: an empty file. Every time you approve or reject something, the reason goes here. After a few weeks it becomes your real style guide.

2. Set up the project

  1. Install Node.js, Git, Claude Code and ffmpeg.
  2. Make a folder, git init, and a private GitHub repo.
  3. Write CLAUDE.md: who you are, the hard rules, the weekly steps, where files go.
  4. Keep secrets in a .env file that git ignores. Never paste keys into chat.

Prompt: Read CLAUDE.md and the brand folder. Set up a Remotion project in remotion/ with our colours and fonts as tokens. Make one composition for a 1080×1920 reel and one for a 1080×1350 carousel. Render one sample of each so I can approve the style.

Don't move on until the sample looks like you. Reject it with reasons until it does.

3. Turn each job into a skill

One file per job, each short. Ours: report, ingest references, trend scan, hooks, scripts, captions, carousel design, reel edit, brand check, publish, taste log.

Prompt: Create a skill called brand-check. It reads the brand folder and the taste log, then checks a script, caption or render for banned words, safe zones, colours, fonts and our hard rules. It returns PASS or a numbered fix list. Run it before you show me anything.

4. Make the weekly run one command

Ours is /weekly. It runs the steps in order and stops at each checkpoint until we reply.

Prompt: Create a /weekly command. Steps: pull last week's insights, process new references, check upcoming dates, plan the week (stop for my approval), write all copy (stop), generate one voice sample (stop), render everything and run brand-check, show me a review table (stop), then schedule only what I approved.

5. Connect Instagram

  1. Create a Meta developer app with Instagram API with Instagram Login.
  2. Add your Instagram professional account and generate a token.
  3. Switch the app to Live, or nobody outside the app's roles can see your replies.

Ask Claude Code to write the publishing code against the official API, and test with one post first.

6. Deploy the Worker

A Cloudflare Worker with a cron trigger every 5 minutes: it reads the week's queue, posts anything due, refreshes the token weekly, checks giveaway comments and replies by DM, and sends Telegram reminders for posts you do by hand (trend-audio reels, YouTube Shorts).

Prompt: Write a Cloudflare Worker with a 5-minute cron. It stores the week's queue in KV, publishes due items through the Instagram API, polls comments on giveaway posts for the keyword and sends one private reply per person, and messages me on Telegram if anything fails. Add a script that pushes the queue from my laptop.

7. Add the Telegram inbox

A bot that only answers your own chat IDs. Messages land in the Worker; a script on your laptop pulls them into dated folders. Voice notes get transcribed with whisper.

Rules we learned

  • Nothing posts without approval. Only items marked approved get scheduled. Always.
  • Log every reason. "Rejected" teaches nothing. "Rejected: the text is too small and nothing moves" fixes next week.
  • No automated engagement. No auto-likes, auto-follows or auto-comments. The only automatic DM goes to someone who asked for it by commenting a keyword.
  • Licensed sound only. Your own library, music you generate, or audio you add inside Instagram.
  • Keep it honest. If AI wrote the first draft, you still own every word that goes out.

What we still do by hand

  • Approve the plan, the copy and every render.
  • Post trend-audio reels and YouTube Shorts (the bot sends us the file and caption five minutes before).
  • Reply to real comments. That part is the point.
